# Backend

API FastAPI con persistencia SQLite. Ejecutar desde la carpeta `backend`:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r ../requirements.txt
python run.py
```

La aplicación web queda en http://127.0.0.1:8000 y la documentación interactiva de la API en http://127.0.0.1:8000/docs.
